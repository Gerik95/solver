# Solver

Solver is a pet project SPA created for an automotive service business.

The project was built with React and focused on clear service presentation, user-friendly structure, and communication with potential clients through a website contact form.

## Overview

This project was created to practice frontend development in a realistic business scenario.  
The main focus was on building a clear and responsive interface for a service-based website, organizing content in a practical way, and implementing simple client interaction through the site.

## Features

- Single-page application structure
- Clear service presentation
- Contact form for potential client inquiries
- Responsive layout
- User-friendly interface
- Business-oriented content structure

## Tech Stack

- React
- JavaScript
- HTML5
- CSS3

## What I Practiced

- Building a React SPA
- Creating responsive layouts
- Structuring components and content
- Implementing form-based interaction
- Translating business needs into a simple and usable interface

## Project Goal

The goal of this project was to strengthen practical frontend development skills by creating a realistic website for an automotive service business and focusing on usability, structure, and clear service presentation.
